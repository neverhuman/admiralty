Date: 20 October 2026, America/Denver. Operational receipts use UTC21October.

## 1. Objective and user contract

The user is an integration owner reconciling concurrent branches and worktrees. The primary journey is **choose a repository → expand that repository → see main as a straight backbone → find work outside the integration target → inspect the evidence → merge, repair, assign, preserve or clean under the existing policy**. Fullscreen fleet posters are secondary. The graph is an investigation surface, not a new source of merge, deletion, provider or deployment authority.

Completion means a selected repository has a padded two-axis fit at any required finite scale, continuous camera navigation, a stable trunk and truthful branch structure, exact reversible compression, branch/integration/worktree inspection, and access to all indexed reachable local history beyond400commits. The source, index progress and browser-resident detail must be distinguishable. An initial loaded-history delivery is useful but does not close the complete-history work.

### Non-goals and forbidden shortcuts

- No change to the required ordinary matched rebase merge policy. No force push, admin bypass, squash or merge commits.
- No automatic merge/delete/prune UI; no new credentials, provider grants, role enrollment, terminal redrive or deployment controller.
- No inferred landing from author/time/message identity, whitespace-stripped patch identity, a branch disappearance or a matching subject. These can produce investigation candidates only.
- No automatic source fetch, Git maintenance, retention refs, checkout mutation or source-index writes by the observer/indexer.
- No new graph framework, gix migration, WASM, WebGL or OffscreenCanvas in the initial implementation. Add acceleration only for a measured unmet budget.
- No claim that all remote/deleted/unreachable/reflog history is indexed. Scope is frozen, configured, locally available reachable objects.
- No speculative native/scientific/full-release claim. Existing native_execution_qualified=false remains a separate boundary.
